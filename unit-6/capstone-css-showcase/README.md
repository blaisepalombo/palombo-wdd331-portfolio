# Capstone CSS Showcase

This project is my final capstone for WDD 331R: Advanced CSS. I chose Option B and built a custom website to demonstrate the CSS skills I learned in this course.

## What this project includes
- Responsive design (mobile to desktop)
- CSS Grid and Flexbox for layout
- CSS variables for consistent styling
- Animations and transitions
- Reduced motion support for accessibility
- SVG or icons
- Modern CSS features

## Purpose
The goal of this project is to show my understanding of modern CSS by building a clean, well-designed, and functional website.
