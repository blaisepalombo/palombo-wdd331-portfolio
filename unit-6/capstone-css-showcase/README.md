# Capstone CSS Showcase

This project is my final capstone for WDD 331R: Advanced CSS. I chose Option B and built a custom showcase site based on modern sport bikes. The site is designed as a polished single-page experience that highlights the CSS techniques covered throughout the course.

## What this project demonstrates

### Foundations and architecture
- Custom properties for color, spacing, shadows, typography, and transitions
- Organized CSS split into `base.css`, `layout.css`, `components.css`, and `pages.css`
- A consistent naming approach using reusable section, card, and component patterns

### Layout
- CSS Grid used for the categories, features, gallery, and featured bike layout
- Flexbox used for navigation and grouped actions
- `grid-template-areas` used in the featured bikes section to create a more intentional highlighted layout

### Visual design and polish
- Layered gradients in the page background, hero overlay, and accent details
- Transforms on hover states for cards and buttons
- Filters and shadows to add depth and contrast

### Motion and accessibility
- Transitions used throughout the interface for hover and interaction states
- Keyframe animation used in the hero area for subtle visual motion
- `prefers-reduced-motion: reduce` support so motion is disabled when needed

### SVG and advanced CSS
- Inline SVG icons used in the Performance Technology section
- Scroll snap used in the horizontal gallery for controlled scrolling behavior
- Responsive design from mobile to desktop

## Purpose
The goal of this project is to show my understanding of modern CSS by building a clean, themed, and responsive website that feels complete rather than just being a list of disconnected examples.
